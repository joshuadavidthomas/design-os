## Step 5: Generate Django Models

Once the user approves the structure, create `product/sections/[section-id]/models.py`:

```python
"""
Django models for [Section Title]

Generated by Design OS based on section specification.
"""

from django.db import models


class Invoice(models.Model):
    """Represents a bill sent to a client for work completed."""

    invoice_number = models.CharField(max_length=50, unique=True)
    client_name = models.CharField(max_length=255)
    client_email = models.EmailField()
    total = models.DecimalField(max_digits=10, decimal_places=2)
    status = models.CharField(
        max_length=20,
        choices=[
            ('draft', 'Draft'),
            ('sent', 'Sent'),
            ('paid', 'Paid'),
            ('overdue', 'Overdue'),
        ],
        default='draft',
    )
    due_date = models.DateField()
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)

    class Meta:
        ordering = ['-created_at']

    def __str__(self):
        return f"{self.invoice_number} - {self.client_name}"


class LineItem(models.Model):
    """Individual service or product listed on an invoice."""

    invoice = models.ForeignKey(
        Invoice,
        on_delete=models.CASCADE,
        related_name='line_items',
    )
    description = models.CharField(max_length=255)
    quantity = models.PositiveIntegerField(default=1)
    rate = models.DecimalField(max_digits=10, decimal_places=2)

    def __str__(self):
        return self.description

    @property
    def amount(self):
        return self.quantity * self.rate
```

### Model Generation Rules

1. **Use snake_case** for field names (Django convention)
2. **Use appropriate field types:**
   - Text → `CharField` or `TextField`
   - Numbers → `IntegerField`, `DecimalField`, `PositiveIntegerField`
   - Dates → `DateField`, `DateTimeField`
   - Email → `EmailField`
   - Boolean → `BooleanField`
   - Choices → `CharField` with `choices` parameter

3. **Include relationships:**
   - One-to-many → `ForeignKey` with `related_name`
   - Many-to-many → `ManyToManyField`
   - One-to-one → `OneToOneField`

4. **Add Meta class** with sensible defaults:
   - `ordering` for default query order
   - `verbose_name` / `verbose_name_plural` if needed

5. **Add `__str__` method** for admin/debugging
